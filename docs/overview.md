# Project Overview

Riot ReImagined is a full-stack web app for Riot Games content, player stats, esports, and account features.

## Stack

- **Frontend:** React 19, Vite, Tailwind CSS, React Router, GSAP
- **Backend:** Node.js, Express 5, MongoDB, Mongoose
- **Auth:** JWT, bcryptjs
- **Utilities:** cors, dotenv, Redis-based caching

## Main Areas

- Riot account and match lookups
- Valorant agents, maps, and esports schedule
- News content
- Login, signup, and profile pages
- Smurf detection and playstyle analysis
