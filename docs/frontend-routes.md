# Frontend Routes

The client uses React Router.

## Routes

- `/` — Home
- `/esport` — Esports page
- `/about` — About page
- `/games` — Games hub
- `/games/:game` — Game-specific page
- `/games/valorant/agents/:id` — Valorant agent details
- `/games/valorant/maps/:id` — Valorant map details
- `/login` — Login
- `/signup` — Signup
- `/news` — News
- `/profile` — User profile
- `/player/:game/:gameName/:tagLine` — Player stats
- `/smurf-detector` — Smurf detector
