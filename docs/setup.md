# Local Setup

## Requirements

- Node.js
- npm
- MongoDB connection string

## Backend

```bash
cd backend
npm install
npm start
```

### Common environment variables

- `PORT`
- `ALLOWED_ORIGINS`
- `MONGO_URI`
- `JWT_SECRET`
- `RIOT_API_KEY`
- `HENRIK_DEV_API_KEY`

## Frontend

```bash
cd front
npm install
npm run dev
```

## Useful scripts

- Frontend: `npm run lint`, `npm run build`
- Backend: `npm run dev`
